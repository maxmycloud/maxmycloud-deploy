Step-by-step installation process

Introduction

This guide provides a comprehensive walkthrough of the MaxMyCloud SAAS software installation process. Follow these instructions carefully to ensure a smooth and successful setup.

Target Audience: System Administrators, IT Professionals

Prerequisites:

  • An active MaxMyCloud subscription
  • Snowflake account with privileges to install apps (ACCOUNTADMIN recommended)
  • A modern web browser

1. Company Domain Setup

Each company will receive its own dedicated URL. Please provide your preferred subdomain in advance.

For example: a company named XYZ may choose a URL such as xyz.maxmycloud.com.

2. List of Snowflake Accounts

MaxMyCloud distributes the Native App through Snowflake Private Listing. To grant your organization access, please provide your Snowflake data-sharing account identifier.

To find this identifier log in to your Snowflake account and click at your user profile at the bottom of the screen → Account → View account details → Copy data sharing account identifier.

Or run the SQL command:

SELECT CURRENT_ORGANIZATION_NAME() || '.' || CURRENT_ACCOUNT_NAME();

If you plan to use MaxMyCloud across multiple Snowflake accounts, please provide identifiers for all accounts.

Before Proceeding
Please share the information gathered from Step 1–2 with the MaxMyCloud team. We will use this to set up your company’s URL and publish the MaxMyCloud Native App to your Snowflake account(s).

3. Install MaxMyCloud Native App

Before beginning, please ensure that MaxMyCloud has published the Native App to your Snowflake organization.

Step 1: Locate and Download the App

In the Snowflake UI, go to Apps. Under Recently Shared with You, locate Monitor Center (MaxMyCloud) and click Get to begin the download.

Step 2: Install the App

Once the download completes, the app will appear under Installed Apps. Click Monitor Center to begin installation.

Select SNOWFLAKE_INSIGHT. Snowflake will start the installation process.

Grant required permissions: during setup, two authorization prompts will appear requesting Snowflake privileges. Click “Grant Privileges” and then “Allow” to continue.

Step 3: Confirm Installation

Installation usually completes in under 30 seconds. A green checkmark indicates the app has been successfully installed.

The Data Refresh process will start automatically. You may click Check Status to monitor progress, but this step runs in the background—it’s safe to close the app window at any time.

Step 4: Create MaxMyCloud role and Assign Users

a. Create the Role

Run the following SQL in your Snowflake worksheet to create the required role. Replace your_warehouse with the warehouse you want MaxMyCloud to use (X-Small is recommended):

CREATE ROLE maxmycloud_role;

GRANT APPLICATION ROLE monitor_center.app_maxmycloud   TO ROLE maxmycloud_role;
GRANT USAGE ON WAREHOUSE your_warehouse                TO ROLE maxmycloud_role;
GRANT USAGE ON INTEGRATION MAXMYCLOUD_API_INTEGRATION  TO ROLE maxmycloud_role;
GRANT IMPORTED PRIVILEGES ON DATABASE SNOWFLAKE        TO ROLE maxmycloud_role;

b. Assign the Role to Snowflake Users

Grant the role to each Snowflake user who will access MaxMyCloud. Replace snowflake_username with the actual Snowflake username (the user must already exist):

GRANT ROLE maxmycloud_role TO USER snowflake_username;

Onboarding

Congratulations!

Your organization is now fully prepared for the MaxMyCloud onboarding process. The MaxMyCloud team will host a live session with you to complete the following:

  1. Configure Snowflake SSO authentication integration. (Recommended for Enterprise).
  2. Set up the maxmycloud service user with key-pair authentication for AI & autosize features.
  3. Create MaxMyCloud accounts for your designated users.
  4. Provide live training on MaxMyCloud’s cost insight dashboards.
  5. Setup Real-Time Monitoring.
  6. Configure Warehouse Optimization Schedules.
  7. Configure Snowflake User groups/teams, including quotas and budget alerts.

Snowflake SSO Setup (Required During Onboarding)

During the onboarding process, you will be asked to create a Snowflake Security Integration to enable Snowflake SSO authentication.

Please follow the steps below (replace company_name with the subdomain you selected in Step 1):

Create Snowflake Security Integration

CREATE OR REPLACE SECURITY INTEGRATION maxmycloud
  TYPE                          = OAUTH
  ENABLED                       = TRUE
  OAUTH_CLIENT                  = CUSTOM
  OAUTH_CLIENT_TYPE             = 'CONFIDENTIAL'
  OAUTH_REDIRECT_URI            = 'https://company_name.maxmycloud.com/api/oauth/callback'
  OAUTH_ALLOW_NON_TLS_REDIRECT_URI = TRUE
  OAUTH_ISSUE_REFRESH_TOKENS    = TRUE
  OAUTH_REFRESH_TOKEN_VALIDITY  = 86400
;

Retrieve the OAuth Client ID and Client Secret

Run the following command and record the generated values:

SELECT SYSTEM$SHOW_OAUTH_CLIENT_SECRETS('MAXMYCLOUD');

If you have multiple Snowflake accounts using SSO, repeat this step for each account.

Service KeyPair Setup (Required During Onboarding)

Snowflake SSO authenticates interactive sign-in — users open MaxMyCloud in their browser and authenticate against your identity provider. However, MaxMyCloud’s background services — the AI advisor, scheduled health checks, warehouse autosize, budget monitoring — run outside any browser session and cannot use SSO. They authenticate to your Snowflake account as a dedicated non-human service identity, using Snowflake’s standard key-pair authentication.

Therefore, every Snowflake account configured with SSO also needs a service KeyPair attached in order for AI & autosize features to work on that account. In the MaxMyCloud UI at Settings → Accounts, an SSO-only account card will show “— needs KeyPair” next to the AI & autosize capability, with a + Add KeyPair action next to it.

a. Generate a key pair on your workstation

openssl genrsa 2048 | openssl pkcs8 -topk8 -inform PEM -out rsa_key.p8 -nocrypt
openssl rsa -in rsa_key.p8 -pubout -out rsa_key.pub

You’ll get two files:

  • rsa_key.p8 — the private key. Keep this safe; you’ll paste its contents into the MaxMyCloud UI in step (d).
  • rsa_key.pub — the public key. Its content goes into the Snowflake user in step (c).

b. Create the Snowflake service user

Run as ACCOUNTADMIN (this creates the same maxmycloud user referenced by the role you granted in Section 3, Step 4):

CREATE OR REPLACE USER maxmycloud
  PASSWORD          = ''              -- empty for key-pair auth
  LOGIN_NAME        = 'maxmycloud'
  DISPLAY_NAME      = 'maxmycloud'
  DEFAULT_WAREHOUSE = 'your_warehouse'
  DEFAULT_ROLE      = 'maxmycloud_role'
  DISABLED          = FALSE;

GRANT ROLE maxmycloud_role TO USER maxmycloud;

c. Attach the public key to the Snowflake user

Open rsa_key.pub in a text editor. Copy the content between the -----BEGIN PUBLIC KEY----- and -----END PUBLIC KEY----- lines — a single block with no line breaks — and run:

ALTER USER maxmycloud SET RSA_PUBLIC_KEY='MIIBIjANBgkqh…';

Verify the key attached correctly:

DESC USER maxmycloud;

Confirm the RSA_PUBLIC_KEY_FP value in the output is non-empty.

d. Attach the private key in the MaxMyCloud UI

  1. Sign in to MaxMyCloud at your company URL (from Section 1).
  2. Navigate to Settings → Accounts.
  3. Find the Snowflake account card for the SSO account you just configured. Its AI & autosize row will show “— needs KeyPair” with a + Add KeyPair link. Click + Add KeyPair.
  4. A green banner at the top of the Add Account page confirms “Adding service KeyPair for <your Snowflake host>”. The Account Name, Account Identifier, and Authentication Mode (Key Pair) are inherited from the SSO card and locked.
  5. Fill in the remaining fields using the mapping below.
  6. Click Add Account at the bottom.
Form field What to enter
Warehouse The warehouse you granted to maxmycloud_role in Section 3, Step 4a.
Username maxmycloud (the service user from step b above).
User Role maxmycloud_role.
Private Key Paste the full contents of rsa_key.p8, including the -----BEGIN PRIVATE KEY----- and -----END PRIVATE KEY----- header/footer lines.

Once saved, the account card will update to show AI & autosize — backed by the service KeyPair. AI advisor and warehouse autosize features are now available for that Snowflake account.

If you have multiple Snowflake accounts using SSO, repeat these steps for each account.
